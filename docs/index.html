FEATURES
BOTH

对局流程

自动接受，自动开始匹配，掉线重连，结算后回到房间，并领取奖励。

BOTH

备战席换英雄

选人阶段点一个头像作为目标，客户端一放行就换上。彩色可以换，灰色是没拥有、也不在周免。

LCU

只走本机接口

不注入进程，不读写内存，不模拟键鼠，不做 OCR。和 Riot、腾讯无关。

WINDOWS

对局时让开

进对局会收起并吸附到客户端右上角。还有托盘、开机自启、WeGame 一键启动。解压后用管理员运行 ARAMHelper.exe。

MAC

贴在客户端右边

Swift 原生。一键启动游戏，窗口贴在客户端右侧，不需要辅助功能权限。只支持 Apple Silicon，第一次请右键再打开。

MIT

安装包在 Gitee

Windows v2.1.0 与 Mac v0.8.0 都在 leexkun/lol-helper 的 v2.1.0 发行版里。下载不经过 GitHub。

03 //

三步上手

HOW TO USE

  1. 下载解压

    Windows 取 xiaobai-helper-windows.zip，解压后用管理员运行 ARAMHelper.exe。Mac 取 xiaobai-helper-mac.zip，第一次右键，再打开。

  2. 连上客户端

    先登录英雄联盟客户端。右上角变成已连接之后，再启动自动化。

  3. 开打，或换英雄

    接受、开始匹配会自己走。进选人后，点备战席头像设成目标，放行就换上。

Windows 10/11，管理员运行。Mac 只支持 Apple Silicon，未公证。两个包都在 Gitee v2.1.0。
04 //

两个问题

FAQ
它动游戏文件吗？
不改客户端文件。它只调用本机官方 LCU 接口。第三方工具没有人能保证零风险，用之前自己看一眼游戏协议。
灰色头像点了没反应？
灰色表示这个英雄没拥有，也不在本周免费里，客户端不允许换。头像墙只在选人阶段、备战席打开时出现。
